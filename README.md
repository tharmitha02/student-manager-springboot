Student Manager

About the Project

Student Manager is a web application developed using Spring Boot to manage student records. It supports creating, viewing, updating, and deleting student information (CRUD operations).

Technologies Used
- Java
- Spring Boot
- Spring Data JPA and Hibernate
- H2 in-memory database
- Thymeleaf
- HTML and CSS
- Maven

How to Run
1. Install JDK 21 or a compatible Java version configured for the project.
2. Open the project in IntelliJ IDEA.
3. Ensure the required Maven dependencies are downloaded.
4. Run `StudentManagerApplication.java`.
5. Open a browser and visit `http://localhost:8080/students`.

Database
The application uses an H2 in-memory database. Student records are cleared when the application stops.

Features
- Register students
- View student records
- Edit student information
- Delete student records
- View Hibernate-generated SQL statements in the application console
